## Categories

- **production_paths** — Production code: user/network input handlers, authorization, business logic, data persistence, security-relevant behavior.
- **test_paths** — Tests, fixtures, harnesses. For Go, includes dirs hosting `*_test.go` files; leaf tests live in production_paths.
- **ci_paths** — CI/CD: `.github/`, `.gitlab/`, `.circleci/`, etc.
- **docs_paths** — Documentation only; no executable code.
- **tooling_paths** — Dev tooling, scripts, `tools/` dirs; not shipped.
- **generated_paths** — Auto-generated or vendored: `swagger/`, `bindings/`, protobuf stubs, third-party assets (`jquery.min.js`, `bootstrap.min.css`, etc.).

Each directory appears in exactly one category. Directories fitting none may be omitted.

## Canonical bucket rules (no deliberation)

These directory names always map to the same bucket — do not place them anywhere else:

- `.github/`, `.gitlab/`, `.circleci/`, `.buildkite/`, `.azure-pipelines/` → **ci_paths**
- `node_modules/`, `vendor/`, `dist/`, `build/`, `target/`, `out/`, `.next/`, `__pycache__/` → **generated_paths**
- `tests/`, `test/`, `spec/` → **test_paths**

If your reasoning trace identifies one of these directories under the canonical name, the JSON output bucket MUST match. Putting `.github/` in production_paths after reasoning that it contains CI configuration is a contradiction — the JSON drives downstream behavior, the trace doesn't.

## Vendored asset detection

When an asset directory (`static/`, `assets/`, `public/`, `media/`, `lib/`) contains files like `*.min.js`, `*.min.css`, `*@<version>.*`, `*-<major>.<minor>.<patch>.*`, or files named after known third-party libraries (`jquery*`, `bootstrap*`, `leaflet*`, `highcharts*`, `echarts*`, `react*`, `vue*`, etc.), the directory is **vendored** and belongs in `generated_paths`. Vendored content is not first-party application code; the pipeline reviews it at lowest priority.

If you see e.g. `gui/static/ancillary/js/jquery.min.js` in the tree, classify `gui/static/ancillary/js/` (or its parent if the whole subtree is vendored) as `generated_paths`. Do not bucket vendored asset directories into `production_paths` because their parent directory is the application source root.
